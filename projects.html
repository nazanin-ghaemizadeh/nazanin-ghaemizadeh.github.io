POROPTO — Portfolio Optimization Package
A Python package for sustainable multi-objective portfolio optimization under a trapezoidal intuitionistic fuzzy framework. It jointly balances return, risk (variance), uncertainty (entropy), and sustainability through an iterative intuitionistic fuzzy linear programming method, validated on real Tehran Stock Exchange data.
 Python, Pyomo, AMPL/Bonmin

Predicting Obesity Risk Using NHANES Data and Machine Learning
A data-driven classification pipeline built on NHANES health and lifestyle survey data (2011–2018, ~7,800 adults). The workflow combines missing-data imputation, physiological feature engineering, recursive feature elimination, and cross-validated tuning of five machine-learning models to classify individuals into five obesity categories.
 R, caret, randomForest, e1071, mice

Process Mining with Real-World Financial Loan Applications
A process-mining analysis of a real Dutch bank's loan-application event log, covering more than 262,000 events across 13,000+ cases. Discovery algorithms and conformance checking are used to uncover bottlenecks, rework loops, and process variants, leading to concrete recommendations for improving process efficiency.
 Python, pm4py, pandas, scikit-learn
